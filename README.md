# Mail Checker (MCK)

Высокопроизводительный многопоточный чекер почтовых аккаунтов на **Rust** с современным нативным интерфейсом на базе **WebView2** / **Tao**.

---

## ⚡ Особенности

- **Высокая скорость работы**: Нативный асинхронный/многопоточный движок на Rust с поддержкой до 500 параллельных потоков.
- **Поддержка почтовых протоколов**:
  - **IMAP (SSL / TLS)**
  - **POP3 (SSL / TLS)**
  - **SMTP (Implicit SSL / Explicit STARTTLS)**
- **Умное автоопределение серверов**:
  - Встроенная база известных почтовых провайдеров.
  - Автоматический поиск через базу Mozilla Thunderbird ISPDB / Autoconfig.
  - Адаптивные эвристики формирования доменных хостов.
  - Динамическое кэширование найденных серверов для ускорения массовой проверки однотипных доменов.
- **Гибкая работа с прокси**:
  - Поддержка **SOCKS5**, **SOCKS4**, **HTTP**, **HTTPS**.
  - Поддержка авторизации (`user:pass@host:port` и `host:port:user:pass`).
  - Автоматическая циклическая ротация прокси-серверов.
- **Поиск и чтение писем**:
  - Поиск писем по критериям: Тема (`SUBJECT`), Отправитель (`FROM`), Текст (`TEXT`), Тело письма (`BODY`).
  - Встроенный модальный просмотрщик содержимого ящиков и найденных писем.
- **Экспорт и классификация результатов**:
  - Автоматическое сохранение валидных аккаунтов и аккаунтов с найденными письмами в файлы (`results/valid.txt`, `results/request.txt`, `results/invalid.txt`).
  - Детальная классификация ошибок: 2FA, Блокировки, Лимиты запросов, Ошибки TLS, Несуществующие серверы.
- **Сохранение настроек**: Все параметры, тайминги, порты и флаги автоматически сохраняются в локальное хранилище и восстанавливаются при запуске.
- **Удобный интерфейс**: Фиксированный размер окна (1180x780), поддержка тёмной темы Windows 11 DWM, быстрые фильтры и статистика в реальном времени.

## 🚀 Установка и запуск

### Требования
- **Windows 10 / 11** (64-bit)
- **Microsoft Edge WebView2 Runtime** (предустановлен в Windows 10/11)

### Сборка из исходников

1. Установите [Rust](https://rustup.rs/):
   ```bash
   rustup default stable-x86_64-pc-windows-msvc
   ```
2. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/domovoyproj/MCK.git
   cd MCK
   ```
3. Соберите релизную версию:
   ```bash
   cargo build --release
   ```
4. Исполняемый файл будет доступен в `target/release/mailcheck.exe`.

> **Примечание:** Файл `WebView2Loader.dll` автоматически копируется в папку с собранным бинарником при компиляции через `build.rs`.

## 📋 Форматы входных данных

### Аккаунты (Учётки)
Текстовый файл со списком почтовых ящиков в формате `login:password` (или `email:password`):
```text
user1@gmail.com:password123
client@company.de:secretPass456
test.mailbox@mail.ru:myPassword789
```

### Прокси
Поддерживаются следующие форматы строк:
```text
127.0.0.1:1080
socks5://username:password@1.2.3.4:1080
http://proxy.server.com:8080
1.2.3.4:1080:username:password
```
